1. Levantar una Terminal. ✅

2. Listar los containers levantados:✅
docker ps
Mismo resultado con:
docker container ls
Se ve algo?
- no

Listar todos los containers:✅
docker ps -a
Mismo resultado con:
docker container ls -a
Se ve algo?
- no

3. Listar las imagenes:✅
docker images
Mismo resultado con:
docker image ls
Que se observa?
- no hay imagenes

4. Bajarse una imagen:✅
docker pull ubuntu

5. Ejecutar pasos 3 y 4 de vuelta. Que sucedio? ✅
- paso 3: se ve la imagen descargada de ubuntu
- paso 4 no seria necesario

6. Crear un contenedor:✅
docker create -t -i ubuntu /bin/bash
-t da una terminal
-i es modo interactivo (-d es modo detachado)
/bin/bash ejecutara (cuando sea levantado) el bash del ubuntu
- se crea el contenedor, devuelve el id completo

7. Ejecutar los pasos 3 y 4. Que sucedio ahora?✅
 - no tiene mucho sentido ejecutar de nuevo los pasos 3 y 4

8. Levantar el contenedor creado en paso 7, utilizando el id devuelto en el mismo, por ej:✅
docker start -a -i 3ace1602e1ae62d940e0e511bbd9cae08d19559fd9a36cd0111bc03a8840fc9b
(tambien se puede levantar con el nombre del contenedor o el id)
-a levanta la standard out.
-i modo interactivo.
- se ejecuta el contenedor 

En otra terminal ejecutar pasos 3 y 4. Que sucedio?✅
- paso 3 muestra la imagen
- paso 4 muestra que La segunda vez, la imagen ya estaba en caché 
y no fue necesario descargarla nuevamente:

15. Ejecutar:✅

Es el "hello world" de Docker, ver lo que hace.
+ Descargó la imagen si no estaba presente.
+ Creó y ejecutó un contenedor con la imagen.
+ Mostró un mensaje de prueba que confirma que Docker está funcionando correctamente.
+ Se detuvo automáticamente después de imprimir el mensaje.
Si ejecutas docker ps -a, verás que el contenedor hello-world aparece 
en la lista de contenedores detenidos

Daemon: 
Disk And Execution MONitor (Monitor de Disco y Ejecución)
Ejemplos de Daemons en Linux y Software
📌 Algunos daemons conocidos:

systemd → Administra el arranque y servicios en Linux.
sshd → Maneja conexiones SSH.
httpd → Servidor web Apache.
dockerd → Daemon de Docker, que gestiona contenedores en segundo plano.
En resumen, un daemon es un proceso que corre en segundo plano y provee 
servicios sin requerir una sesión activa del usuario.
